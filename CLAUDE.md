# Portfolio site for Jivitesh Singh
Single-page portfolio for software + electrical/computer engineering job applications.

## Rules
- Stack: Astro or plain HTML/CSS/vanilla JS. No UI libraries.
- Source of truth for facts: assets/resume.pdf. Never invent numbers or dates.
- Never show my phone number on the site.
- All colors, spacing, radii are CSS variables. One teal accent, Inter + JetBrains Mono.
- Project content lives in projects.json; do not hardcode projects in markup.
- Must stay Lighthouse 90+ and keyboard accessible. Respect prefers-reduced-motion.
- Deploys to GitHub Pages.

## Workflow
- After each change, run the build and fix errors before reporting back.
- Commit in small steps with clear messages.
